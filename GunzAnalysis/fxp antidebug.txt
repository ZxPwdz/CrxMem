Key Technical Info
------------------
  Process: Gunz.exe (32-bit, runs under WoW64)
  PE Base: 0x00130000 (ASLR — varies per launch, use RVA format Gunz.exe+offset)
  kernel32 (32-bit): 0x75F30000
  ntdll (32-bit): 0x77760000
  Pointer table base: 0x008BA000 (RVA 0x78A000)

  Calling convention: ALL imported APIs go through a LOCAL POINTER TABLE at 0x008BA000.
  The code uses FF 15 [ptr_addr] (indirect call) where ptr_addr contains the actual
  API address. This is NOT the traditional PE IAT — it's a custom secondary table.

  IAT (traditional): at RVA 0x2F310AC (kernel32), also populated but not used by FF 15.
